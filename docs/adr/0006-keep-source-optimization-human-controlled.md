# Keep source optimization human-controlled

Quality Ratings and Lead Dispositions produce Source Performance metrics and same-niche Source Recommendations, but recommendations never alter acquisition automatically. Legacy Lead Outcomes remain available until their feedback evidence is migrated into those canonical records. Administrators approve immutable Scraper Configuration versions, every Scrape Run records its version, rollback selects a prior version without rewriting history, and activation waits for the next nightly run unless an administrator separately starts a manual run.
