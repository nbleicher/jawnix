## Agent skills

### Location

Skills live in `.agents/skills/` (canonical; managed by the skills installer, see `skills-lock.json`). `.claude/skills` is a symlink to it for Claude Code discovery — do not add real files there.

### Issue tracker

Issues and PRDs are tracked in this repository's GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the five canonical labels with their default names. See `docs/agents/triage-labels.md`.

### Domain docs

Domain documentation uses a single-context layout. See `docs/agents/domain.md`.
